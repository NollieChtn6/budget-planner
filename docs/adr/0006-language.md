# ADR-0006 : Langue

- **Statut** : acceptée
- **Date** : 2026-09-24

## Contexte

Le métier se pense en français, mais l'écosystème technique est en anglais.

## Décision

Interface en français ; code, noms de fichiers et commits en anglais, avec les noms de la colonne Code du [glossaire](../domain/glossary.md). La documentation est rédigée en français.

## Conséquences

- Le glossaire sert de dictionnaire entre les deux langues.
